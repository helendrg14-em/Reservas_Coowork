# Guía de uso

## Cliente

Entre con una cuenta o regístrese. En Inicio elija un espacio y pulse Reservar. Indique un horario futuro, seleccione los equipos y revise el costo. Una reserva pendiente futura aparece en Pagos pendientes y permite confirmar el registro. Si comenzó sin confirmar, se muestra Vencida y debe reprogramarse. No se permite pagar una reserva ajena, cancelada o vencida.

Puede adjuntar una imagen o PDF de hasta 5 MB. La referencia es opcional; el sistema genera una si no la escribe. La confirmación es simulada y no realiza cobros bancarios. Consulte el detalle del pago para ver su comprobante.

## Administración

Espacios asigna el código según el tipo; Equipamiento asigna su código automáticamente. No hace falta escribirlos. Un cambio de tipo de espacio puede cambiar su código. Las fotografías aceptan JPG, PNG o WEBP de hasta 5 MB. Al editar puede conservar, reemplazar o quitar la fotografía.

En Reservas busque al cliente por nombre, elija espacio y horario. Se valida la disponibilidad y la duración máxima de siete días. En Pagos puede registrar pagos para reservas válidas, adjuntar o sustituir comprobantes y registrar reembolsos. Cada reserva admite un solo pago.

Reportes muestra totales del filtro completo; la paginación limita las filas visibles, y la impresión incluye todo el resultado. Los comprobantes solo están disponibles para su propietario y para administración.

## Si SQL está ocupado

Espere y revise si la operación ya aparece antes de repetirla. El sistema reintenta fallos transitorios y evita guardar reservas parcialmente. Si no puede conectar, compruebe que LocalDB está instalado y que la instancia MSSQLLocalDB está iniciada. Conserve la base y sus respaldos; no borre datos para resolver una conexión.
